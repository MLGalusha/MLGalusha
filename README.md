# Mason Galusha

Raleigh-Durham based self-taught software engineer focused on full-stack product work, applied AI, and systems that solve real operational problems.

I am looking for junior to early-career software engineering roles, especially full-stack, backend, and AI-adjacent work. Local Triangle roles are ideal, and I am also open to strong remote opportunities.

## What ties my projects together

I like building real systems, not isolated demos.

- I build products around messy real-world inputs like historical letters, audio files, staffing constraints, and job-search workflow.
- I care about end-to-end execution: data flow, user-facing product, automation, and the operational details that make a system actually usable.
- I spent 2025 deliberately coding by hand to build fundamentals first, then started using agents where they genuinely increase speed and leverage.

## Selected work

### Voices That Remain

Live site: [voicesthatremain.com](https://voicesthatremain.com)

A production digital archive for historical personal letters. I built the full-stack system along with an AI-assisted transcription and metadata pipeline on Google Cloud. The repo is private because it contains real archival material and production credentials, but the live product is public.

### SonicGen

Repo: [MLGalusha/SonicGen](https://github.com/MLGalusha/SonicGen)

A handwritten Python audio fingerprinting engine inspired by Shazam-style matching. This was built without coding agents and ended up around 14,000 lines. It is the clearest example of my ability to design and build a complex system from scratch.

Start here: [SonicGen deep dive](https://github.com/MLGalusha/SonicGen/blob/main/DEEP_DIVE.md)

### PianoTranscriber

Repo: [MLGalusha/PianoTranscriber](https://github.com/MLGalusha/PianoTranscriber)

My UNC Chapel Hill AI bootcamp capstone. An ML system for transcribing solo piano performances from MP3 into MIDI and sheet music using deep learning.

### Staffclaw

Repo: [MLGalusha/staffclaw](https://github.com/MLGalusha/staffclaw)

A full-stack TypeScript scheduling system inspired by real problems I saw working in restaurant operations. Good example of product thinking shaped by an actual workflow instead of a toy prompt.

### Job Tracker

Repo: [MLGalusha/job-tracker](https://github.com/MLGalusha/job-tracker)

An event-sourced, agent-native job search pipeline that sources roles, tracks application state, and generates tailored application materials from a single source of truth. This project is less about flashy UI and more about systems design, automation, and practical multi-agent orchestration.
